# Convex Optimization, Algorithms and Applications

Course by Alexandre d'Aspremont. [Course page](https://www.di.ens.fr/~aspremon/OptConvexeM2.html)

The course teaches how to recognize, reformulate and solve convex optimization problems. These problems show up in machine learning, finance and signal processing. It starts with convex analysis and duality, then moves to algorithms such as first-order methods and interior point methods, with their complexity bounds. It ends with applications.

## Topics by class

1. **Introduction.**
2. **Convex sets.**
3. **Convex functions.**
4. **Convex optimization problems.**
5. **Duality.**
6. **Unconstrained optimization.**
7. **Equality-constrained optimization.**
8. **Barrier method.**
9. **First-order methods.**
10. **Applications.** Machine learning, statistics, signal processing, combinatorial problems and finance.
11. **SDP applications.**
12. **L1 penalties.**
